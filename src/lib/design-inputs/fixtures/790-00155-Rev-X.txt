                              Solea Model 3 Software and Firmware Verification Test Plan



     1. PURPOSE
     The purpose of this document is to provide a test plan for the Solea Model 3 software versions 4.7.0 and
     4.7.1 Solea Model 3 CAN module firmware version 3.9.0, and Solea Model 3 Service Utility software
     versions 1.6.0.


     2. SCOPE
     This test plan applies to the Solea Model 3 software version 4.7.0 and 4.7.1, Solea Model 3 CAN module
     firmware version 3.9.0, and Solea Model 3 Service Utility software version 1.6.0. Note that the Service
     Utility software is an internal diagnostic software designed to be used by Convergent Dental employees
     for troubleshooting purposes and is not user facing.

     Note that Convergent Dental’s software version control system (VCS) has four components that uniquely
     identify the release:
     mm.nn.ff.bb, where:
     ▪        mm: represents major release number (01, 02, etc.)
     ▪        nn: represents minor release number (01, 02, etc.)
     ▪        ff: represents fix release number (01, 02, etc.)
     ▪        bb: represents build number (01, 02, etc.)
     The build number is considered an internal identifier and may not be displayed to the customer. In cases
     where the build number is omitted, the fix release number defines the release. There is only one
     combination of major, minor, and fix number for each release.

     This test plan is used as a verification activity for Solea Model 3 system configurations defined in TOP-
     00051 and TOP-00017. A list of references specific to the scope of this test plan are shown in the table

     2.1     Model Testing
     Solea Model 3 comes in two hardware configurations, TOP-00017 and TOP-00051. Some functionality
     and features may not have to be executed on both platforms due to the reasons listed below in Table 3.
     Requirements that are identified as only needing to be verified on one of the platforms must be
     identified in the scope sections below accompanied with one of the justifications from Table 3.

     The hardware differences between TOP-00017 and TOP-00051 that are significant to the software are
     the laser and the laser controller. In most other aspects the two systems are the same from the
     perspective of the software.

     The general rule is that all requirements that are related to controlling or monitoring the laser will be
     verified on both platforms. Also, all requirements related to calibration will also be verified on both
     platforms.

     However, software version 4.7.0, CAN firmware version 3.9.0, PCON firmware version 1.2.1 and service
     utility version 1.6.0 (and future versions) will support the implementation of the PCON (SUB-00302) laser
     controller for use in TOP-00017 systems as a field replacement option for the LCD-2 laser controller. As a
     result, there will be three unique laser and laser controller configurations for the Solea Model 3,
     applicable to software and firmware versions captured in Rev. W (and subsequent revisions) of this test
     plan. Requirements relevant to the laser and laser controller will be identified in the scope sections
     below via one of the justifications from Table 2.

     2.3     Scope – Solea Model 3 Software Version 4.7.1
     The following are the major changes to software version 4.7.1:

         •   Installer Update to prevent file loss during software updates
         •   Fixed issue where minimum pulse width wasn’t enforced during ramp
         •   Addition of logging and hardening of software to aid determining root cause of intermittent issue
             where the laser doesn’t fire when user steps on the foot pedal.
         •   Fixed an issue with error recovery for cases where the PCON device was required to be reset
         •   Fixed an issue to ensure that the default PCON serial port is not attempted to be utilized on a
             system if another device (e.g. cell modem, foot pedal) is already dedicated to access that serial
             port.
         •   Fixed issue where the galvos are not homed correctly on systems with PCON laser controller.

             Software version 4.7.1 is intended to be a full market release. Testing will be partially executed.

     The change to the Solea model 3 firmware version 3.8.1 is:

     •         For the Palatal Coagulation pattern, the time before issuing a “no laser pulse detected” error
               (1040) is extended by 150ms to allow a wider tolerance for system timing variabilities.

     both TOP-00017 and TOP-00051 and are listed in the Verification and Validation Plan in Section 3.
