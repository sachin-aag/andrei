Turn plan and step policy

At turn start the harness snapshots a ChatTurnPlan. On every model step it runs prepareReportChatStep and returns the only tools the model may call. Characterization tests lock first-step behavior so a “simpler” change cannot silently reopen a 273-page walk.

Built in assembleChatTurnPlan (turn-plan.ts). Downstream code must consume this object instead of re-classifying the same user text.

6. Remaining-sections queue

When the engineer asks to fill several empty draftOrder sections, Agent persists chat_sessions.pending_plan. Each turn drafts the current item (two adjacent non-inventory sections may share a turn). After persist the client POSTs Continue the remaining sections. with autoContinue.

  • MJ ELR evidence sections stay in progress until the same turn also drafts the assessment (a count in narrative, plus trend / overallGrade / recommendation).
  • Cancel or a new typed prompt pauses the queue. Reopening a thread does not auto-chain.
  • A matching finish_document_review this turn unlocks edit_table; do not force another start because the table is still empty — unless the finish was a floor-8 skip that never queued the evidence file (e.g. PRQR).
