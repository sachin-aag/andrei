This is the read path. Briefing 3 wrote document_pages, document_outline_spans, and document_chunks (pgvector + English FTS). This briefing queries those rows. Search finds candidate pages. Document review walks a queued set. Grounding decides whether a drafted fact may persist.

Reads what ingest wrote. There is no Pinecone, no Elasticsearch, no BM25 index. Vector = document_chunks.embedding <=> (HNSW cosine). Keyword = to_tsvector('english', contextual_text) @@ websearch_to_tsquery. Both arms fuse with reciprocal rank fusion (k=60). See briefing 3 if those tables are a blank.

5. Citation ledger and fact gate

Hard facts (dates, identifiers, measured numbers) in draft_field / propose_edit / edit_table must match a quote on a page this turn retrieved. Empty ledger or pages with no served quotes fail open.

Figure 4. The model can still hallucinate a batch number. The harness is the last gate before an ai_fix comment is written.

What counts as a quote

  • Search hit snippet (budget 900 chars)
  • read_document_page transcript (12k chars)
  • Every walked page on finish, not the 60-finding sample

What does not count

  • The Documents index / documentSummary
  • Filename-only [file.pdf] with no page
  • Cover-sheet hits (divider=true)
  • Prior-turn findings unless compacted into citationDigest

7. Clicking a citation

In the document, chat, or suggestion Sources, [filename, p. N] (or numbered [n] mapped to a parked source) opens or reuses that attachment’s canvas tab and scrolls the PDF. Combined [file A, p. N, file B, p. M] splits into one link per file. Word preview cannot jump to a page. Missing or ambiguous filenames toast. Open canvases stay mounted while you switch to Report so the PDF does not re-parse.
